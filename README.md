## نبذة

**وتيره** تساعد الجهات على التأكد من أن أدلتها تثبت فعلاً كل شرط من شروط متطلبات الامتثال، قبل موعد التقديم.
ترفع الجهة مستنداتها، فتقرأها المنصة وتطابق محتواها مع شروط كل متطلب، وتُظهر موضع الدليل بدقة، والفجوات، وما يلزم لاستكمالها.

## المزايا

| | الميزة | الوصف |
|---|---|---|
| 📄 | **قراءة الملفات** | PDF وWord (.docx) وExcel (.xlsx) وTXT، مع معالجة خاصة للنص العربي |
| 🔍 | **فحص الشروط** | حكم لكل شرط: مدعوم مبدئيًا، جزئي، أو ناقص، مع الجملة التي استند إليها وتظليل العبارات المطابقة |
| 📅 | **التحقق من التواريخ** | يفهم التواريخ الميلادية والهجرية والأرقام العربية، ويتأكد أنها داخل دورة القياس |
| ⚠️ | **كشف المسودات** | عبارات مثل «مسودة» أو «قيد الاعتماد» تخفض الحكم تلقائيًا |
| 👤 | **مراجعة المختص** | اعتماد الشرط أو رفض الدليل مع ملاحظة تظهر في التقرير |
| 🗓️ | **خطة الاستكمال** | مسؤول وموعد لكل فجوة |
| 📈 | **توقع الجاهزية** | منحنى التغطية المتوقعة حتى يوم التقديم ومقارنتها بالمستهدف |
| 🧩 | **مكتبة قابلة للتعديل** | إضافة المؤشرات والمتطلبات والشروط وتعديل قواعدها دون برمجة |
| 📊 | **التقارير** | تقرير جاهز للإدارة، وتصدير الفجوات بصيغة CSV |

## كيف يعمل الفحص؟

1. **الاستخراج:** يُقرأ نص الملف داخل المتصفح، ويُطبّع (إزالة التشكيل، توحيد الهمزات والتاء المربوطة والأرقام).
2. **المطابقة:** لكل شرط مجموعات من العبارات المترادفة؛ يُعد الشرط مدعومًا عند ظهور عبارة من كل مجموعة في الجملة نفسها أو التي تليها. في Excel يُقرأ كل صف مع عناوين أعمدته.
3. **التواريخ:** شروط التنفيذ تتطلب تاريخًا داخل دورة القياس قرب السياق.
4. **المراجعة:** للمختص الكلمة الأخيرة في كل حكم.

## الخصوصية

لا تُرفع الملفات إلى أي خادم. تتم القراءة والتحليل بالكامل داخل متصفح المستخدم، ويُحفظ النص المستخرج محليًا فقط، مع إمكانية تصدير نسخة احتياطية واستيرادها.

## التشغيل محليًا

لا يحتاج المشروع إلى بناء أو تثبيت. افتح المجلد عبر أي خادم ملفات بسيط:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## هيكل المشروع

```
index.html        الواجهة والتصميم
js/app.js         منطق التطبيق والشاشات
js/engine.js      محرك الاستخراج والتحليل
js/rules.js       مكتبة المؤشرات والقواعد الافتراضية
brand/            الشعار وصور الهوية
vendor/           مكتبات قراءة PDF وWord وExcel
fonts/            الخطوط العربية
```

## حدود النسخة الحالية

- المؤشرات والقواعد الافتراضية **توضيحية**، وتُستبدل بالمتطلبات الرسمية للجهة.
- ملفات PDF الممسوحة ضوئيًا (صور) وصيغة Excel القديمة (.xls) غير مدعومة بعد.
- البيانات خاصة بكل متصفح؛ لا توجد حسابات أو مشاركة بين فريق في هذه النسخة.
- التقييم داخلي مبدئي، ولا يمثل نتيجة رسمية لأي جهة قياس.
